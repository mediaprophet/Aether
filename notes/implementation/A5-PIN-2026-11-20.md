## Identity

Aether is a QualiaDB-native GUI **toolkit**. It is not the Webizen app. Hosts path-pin these packages.

## In the slice (use these)

- `packages/native/**` with old-web engine feature off (`chora` cargo feature; that id is not the Qualia Chora product)
- `packages/native-dom/**`
- `packages/aether` `feature = "native"` → `aether-native`
- Untracked but **required to compile dirty native:** `packages/native/src/asset_access.rs`, `vendor/blitz/**`, `packages/native/examples/native_lifecycle_smoke.rs`

## Two webs

Human-centric chrome is Aether native RSX (this B1a slice). **Chora** is Qualia’s spatial commons canvas. Old-web documents use the **Servo-derived MPL engine** (repo currently misnamed `WebCivics/chora`), employed as a sibling worker — not WebView, not Wry. B1a leaves cargo feature `chora` **off** so the toolkit window compiles. B1b enables that feature + `chora_frame.rs` + `{install}/chora-worker`.

## Out of the B1a default check

- `packages/native/src/chora_frame.rs` compiled only with `--features chora` (B1b)
- `packages/chora-worker`, `chora-bridge-protocol`, `packages/qualia-host` (workspace `exclude`)
- Frozen v4 / WDAC / pixels / Vibe eval
