# Canonical QualiaDB host adapter

Copyright (c) 2026 Timothy Charles Holborn. CC-BY-NC-ND-4.0.

This is an application-composition crate above Aether's reusable UI crates. It
has a required `qualia-core-db` dependency and provides `scoped_native_runtime`
using the actual canonical `ScopedEffects` and `WebizenSentinelGate`. The generic
adapter requires the caller's real QualiaDB `vibe::Host`, authoritative
`vibescript_abi::SentinelPolicyGate`, and host-issued capability IDs. It offers no
default database, local fallback, policy authority, JavaScript evaluator, GPU
device, or substitute SDK. It is an independent, unpublished Cargo workspace while
the ecosystem's native dependency sources are being qualified.

The resumed local integration selects the actual sibling QualiaDB source paths
for the engine, ABI, core and cooperative contracts. The original checkpoint was
revision afbe431195167fde0fadc233ed79fd2fe85f73f0. The new authority-owned graph
contract is uncommitted canonical source work and cannot be represented by that
old immutable revision. The host's external dependency lock is generated by Cargo;
release qualification must pin a reviewed canonical commit and coherent Etalon
sources across renderer consumers.

The graph profile adds NativeGraphBridge, native_graph_runtime and
native_ui::use_qualia_graph. The native authority issues scopes only after an
independent project-issuer signature and current key-possession session validate.
Graph writes acknowledge the existing authority journal before publication; graph
subscriptions coalesce exact-context snapshots. Read [the continuation record](../../notes/implementation/resume-host.md)
for boundaries and verification.

## Embed the project graph profile

The native application must supply an already-adopted `Arc<NativeAuthority>`, its
current `SessionHandle`, an independently issuer-signed `SignedGraphGrant`, and
its actual `WebizenSentinelGate`. Graph permissions do not come from Vibe source.
The signer grants one exact context; data remains in the native authority journal,
separate from the daemon-global graph and its SPARQL services.

```rust,ignore
use aether_qualia_host::{
    ExecutionLimits, NativeGraphBridge, native_graph_runtime, ui_channel,
};
use std::sync::{Arc, atomic::AtomicBool};

// These values come from the application's real adopted native owner and signer.
let view = NativeGraphBridge::connect(authority.clone(), &session, &signed_grant)?
    .subscribe()?;
let cancelled = Arc::new(AtomicBool::new(false));
let (sender, receiver) = ui_channel(4, || {})?;
let runtime = native_graph_runtime(
    authority, &session, &signed_grant, sentinel, ExecutionLimits::default(),
    sender, cancelled.clone(),
)?;
// Move runtime to the script owner. Keep receiver and view on the native UI owner.
// In an Aether component, native_ui::use_qualia_graph binds view polling to the
// component task. Pass the same cancelled token and a real event/timer tick source.
// native_ui::use_qualia_delivery receives bounded script results on the UI owner.
```

`use_qualia_graph` cancels the script token and closes the view when the component
unmounts or its task/VirtualDom is dropped. Busy polls preserve the prior view;
authentication/stale errors require clearing private displayed content. Read and
query results are snapshots released at an authorized read boundary, not revocable
memory: consumers must not assume previously copied results vanish on revocation.
A native journal append already underway cannot be rolled back by cancellation.

`native_graph_runtime` reserves two scope-sized quin buffers and 256 KiB of
bounded cold host bookkeeping/term scratch from the canonical `vibe::Budget`
before buffer allocation, then passes only the remainder to the interpreter.
Term text is limited to 32 KiB per graph operation; capability identifiers to
4096 bytes. Canonical query result list cells receive a separate conservative
per-call charge in Vibe's shared evaluator/bytecode/scheduler router before the
host runs; failed calls do not refund successful charges. Query rows are inline
six-lane QuinRefs and have no nested string backing. This semantic accounting is
not a process-wide allocator quota. Shared authority graph/journal storage, the
UI view's separately bounded snapshot, mailbox retention, parsing and application
copies have distinct owners and bounds. Direct host composition should use
`NativeGraphHost::new_with_budget`; `new` uses an independent default host budget.

## Headless native startup

The [native_graph example](examples/native_graph.rs) uses actual canonical services
and has no embedded test credentials. Compile/run its help with:

```powershell
cargo run --manifest-path packages/qualia-host/Cargo.toml --example native_graph -- --help
```

Supply the existing journal directory, explicitly adopted project/issuer/public
key, retained signed admission, source revision, admitted subject, signed graph
grant and Vibe source. The process prints a one-use session challenge and reads a
signature produced by the existing enrolled controller under the canonical session
signing context. The private key stays with that controller. It then executes Vibe,
receives the result on the owner-thread mailbox and reports the last acknowledged
native graph commit. It neither creates grants nor enrolls people or instruments.

The example intentionally grants no implicit extension permits. Native graph
rights are validated by the signed authority contract. It is a headless startup
and persistence path; a native window, platform input and GPU qualification remain
separate from this executable.

## Native window application

The [native_graph_window source](integration/native_graph_window.rs) is registered
as an example by the opt-in local native+host integration consumer. It uses the
same explicit signed-input startup and external signing challenge as the headless
example. The standalone host workspace deliberately does not select a renderer.

With the reviewed generated consumer, run its `native_graph_window` example using
the nine startup arguments above. Its native window displays the exact-context
graph snapshot and permits one execution of the supplied Vibe source on a worker.
The component polls on a real 100 ms timer, applies snapshots and result messages
on the UI owner, and clears private previews on authority failure. It shows at
most 16 quins with all six lanes. Busy journal operations preserve the previous
view until a later tick.

Closing the owner cancels further work. Joining the cooperative worker and
disconnecting its session occur outside the event loop after the native launcher
returns, not inside a component callback. Publication never waits for a UI
acknowledgement. A commit already acknowledged by the journal remains durable even
if execution or UI delivery subsequently fails, and the worker reports that last
receipt to the terminal. This source is an application integration path; physical
window/GPU, input, restart and packaging evidence must still be recorded separately.
